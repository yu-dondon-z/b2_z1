## 改动

VD4 仅替换前视几何路径命令生成器使用的相机标定：

- 使用本机 2026-09-15 标定的安装位置 `(0.44643878, -0.00569431, -0.00031663) m`。
- 光学坐标转换为 base `(x前,y左,z上)` 后，RPY 约为
  `(-0.983°, 1.402°, 0.350°)`，接近水平并略向下。
- 实机内参 `(756.700, 752.123, 934.705, 510.684)` 来自 1920×1080 图像。
  VD4 几何图像缩放到 640×360，使用方形像素与居中主点近似
  `(fx,fy,cx,cy)=(251.47,251.47,320,180)`，以符合当前 Isaac 相机配置约束。
- `0.05–5 m` 仍是仿真几何投影的裁剪范围，不是 RGB 相机测距范围。

速度命令公式、策略观测/动作维数、机械臂目标命令和 VD3 任务保持不变。
路径点依然由仿真生成，不读取 RGB 图像；没有模拟畸变、遮挡、裂缝误检或
视觉帧时延。因此 VD4 是标定几何对齐，不是端到端视觉训练。
