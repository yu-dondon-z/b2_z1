# VD9 连续训练与双问题验收（2026-11-12）

## 范围和起点

唯一要改善的现象：机械臂/枪尖左右振荡，以及 B2 的落脚砸地。速度跟踪和枪尖目标位置精度是防止“站得稳但不干活”的硬性保护指标，不作为额外优化主题。训练期间不调奖励、增益、动作接口、接触时间或 actor 输入。

旧 VD9 `model_1500` 的后续 500 轮重置了 optimizer 和 curriculum，不能与之前的 1500 轮合算成连续训练。旧 VD9 1800 轮所有 checkpoint 又缺失 curriculum 状态，不能无损恢复；不凭空构造这个状态。旧训练入口还把 VD9 排除在 VD5 Startup 任务集合之外，导致起始 episode 计时随机化。已修正起步时钟，并让 VD9 保存 `vd5_initial_curriculum.json`；保存的 VD9 checkpoint 本身已有完整 curriculum 状态。本次从**未改变的 VD5 Startup `model_4498.pt`** 开始一条独立、不中途重置优化器的完整训练，不在旧短训分支继续。

起始检查点 SHA256 `9af8e2ca67382d3186bb9ea145930c25797b06e6189963bb1d996fee91f3fedf`。唯一额外训练目标仍是 VD9 已有的 200 Hz TCP 高频与近地面下降速度项。记录 `run_name=vd9_continuous_startup_clock_4000`，使用 256 环境、seed 42、4000 轮的第一阶段预算，每 100 轮保存、保留全部 checkpoint；预算上限不是“已收敛”的判定。每次恢复只用该新 run 自己的 checkpoint + `--resume`，不得再重新 warm start。磁盘剩余约 22 GB，预计检查点不到 1 GB；不清理旧产物。

## 如何判断而不是只看轮数

- 每 200 轮查看滚动训练统计：回报、回合长度、枪尖位置误差、TCP 高频项、落脚项、速度误差、失稳/触地终止。中途的 checkpoint 只用于确认没有 NaN、崩溃或持续性严重退化，不拿单个短期 MuJoCo 会话选最优轮次。
- 在至少 600 轮的连续后期窗口内，检查关键指标的水平和趋势；回报平台不能替代枪尖误差、终止率与速度稳定。若达到首阶段预算仍在明显漂移，明确报告“未证实收敛”，可从**本 run** 精确恢复继续一段较长训练，不直接调奖励。若数值异常或持续的回合崩溃/跟踪丧失，则停止并诊断，不为凑轮数强行继续。
- 只有优化过程趋稳且无明显健康问题，才进行定量验收：Isaac 与 MuJoCo 用相同 200 Hz 物理 / 50 Hz actor、0.70 m 和 0.80 m、固定速度/机身系目标的条件，对比 VD5 4498。机械臂看枪尖 **Y 向** 3 Hz 高频 RMS 和三轴 RMS；B2 逐足看真实 200 Hz 接触持续时间、5 ms 短接触、摆动抬脚高度、触地前下降速度、触地后 40 ms 足力峰值，不能用“零次严格 touchdown”或足力均值假装改善。
- 枪尖目标位置偏差和速度误差不得为了抑振而明显恶化；世界路径误差另验，不代替上述两项。通过固定场景也仅能升级为**候选仿真策略**：再做独立初态/速度扰动与横纵向检查，之后才讨论是否更换仿真默认 actor。VD5 4498 继续作为部署基线，无板载同步或实体控制。
