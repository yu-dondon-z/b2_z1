统计限制：

- 世界向量先做四阶零相位滤波，再按同帧基身 yaw 定义前后/左右；不是焊缝法向。
  这是离线验收口径，与训练的双级因果滤波不同，数值不能当作同一个奖励量。
- 启动前 2 s 和滤波两端各 0.5 s 不计入 TCP RMS，所有信号按实际 reset 切段；
  0.5 s 裁切对 0.5 Hz 较短，不能保证完全消除边界暂态。
- 实际 TCP 低频含期望路径运动，跟踪误差频带另列。50 Hz 目标原始阶跃是记录
  真值，另列的线性插值仅是离线敏感性诊断，不冒充连续目标或输入 actor。
- 枪轴误差是无符号夹角，不能当成有符号的左右角摆动。
- 每足至少连续 20 ms 向上力 <=10 N 后，首次 >10 N 才算落脚；初始支撑和短暂
  力阈值抖动不计新落脚。统计包含首接触帧及随后 50 ms 的 11 个采样点；冲量用
  该窗口积分，不是全步态冲量。窗口不足或跨复位的事件剔除。
- 单种子、单探针工况不是全步态或跨引擎验收。

## 本版修改及边界

VD11 继承 VD10 的 2.93 kg 枪、安装、TCP、碰撞、惯量、驱动、限速、50 Hz actor /
200 Hz physics、安全起点、复位修复、2 s 启动及真实接地/倾倒终止。观测和网络形状
不变，不引入 actor 特权信息。位置/轴向跟踪等既有任务奖励保持不变。

1. **改正抖动项输入定义。** 原项将实时机身系 TCP 与 50 Hz 才刷新的机身系
   target 做差，四个物理子步内没有同步坐标更新；底座运动可混入不属于世界 TCP
   抖动的信号。VD11 移除该项，仅对真实世界 TCP 做两级串联因果高通，再用当前
   yaw 加权左右方向。它不读取目标阶跃，不插值或预测观测/接触。
   两级滤波让匀速运动的稳态残差趋零；复位首个实测样本播种，前 2 s 连续预热
   但不罚。每级滤波参数为 **1 Hz**，覆盖更多测得的步态频段，不是硬频率截断；
   两级串联在 1 Hz 的总幅值响应约 0.5（−6 dB），不是整体的 −3 dB 截止点。
   死区 1 mm、尺度 5 mm、左右系数 2、权重 −0.3。
2. **真实落脚冲击项。** 保留 VD9 原预触地下行项，另外对实际足部 Fz 的落脚
   窗口增加峰值超限平方惩罚。接触/rearm/50 ms 定义与诊断一致，包含接触首帧；
   采用 running-maximum 的正增量，同一事件只累计到最终峰值一次，按 actor dt
   正确换算后交给 RewardManager。四足取均值，权重 −0.5。
   按测得的 270–404 N p95 分布，使用 **300 N 软目标、200 N 尺度**；最初考虑的
   804 N 会漏掉本次几乎所有已见落脚，因此没有用它作为正式配置。
   300 N 不是硬件安全载荷、接触篡改或新终止阈值。
   在线会累计终止前已测得的峰值；离线统计剔除不足完整 50 ms 窗口的事件，
   因而两者事件定义一致，但实际纳入的样本集合不完全相同。
3. **保守学习设置。** 学习率 `2e-5/fixed`，熵系数由 0.01 降到 0.002，减少
   继续训练时维持高随机动作的激励；不是执行时动作滤波，也不承诺 std 必然下降。
4. **隔离和恢复。** 新任务 `Unitree-b2z1-VD11-Velocity`，独立实验
   `b2_z1_vd11_motion_quality_amp`。默认从已完成的 VD10 `model_5998.pt` 加载
   policy/critic、AMP 与完整地面课程/profile，重置 optimizer 和 iteration。
   只有显式 `--vd11-from` 能跨版本迁移；VD11 `--resume` 检查版本、恢复优化器
   和课程。不能把 VD10 的 optimizer 当作新奖励的同版本续训。

实现：[`b2_z1_vd11_env_cfg.py`](../../../source/b2_z1/b2_z1/tasks/manager_based/b2_z1/b2_z1_vd11_env_cfg.py)、
[`vd11_physics.py`](../../../source/b2_z1/b2_z1/tasks/manager_based/b2_z1/mdp/vd11_physics.py)、
[`vd11_rewards.py`](../../../source/b2_z1/b2_z1/tasks/manager_based/b2_z1/mdp/vd11_rewards.py)。

这些修正针对已确认的目标定义缺口；不是已证明它们是全部振荡/砸地的唯一根因。

## Ctrl+C 后同版本续训

先等待旧训练进程退出，再从这次长训系列的最新目录/完整检查点恢复：

```bash
cd /home/dong/b2_z1_VD2
bash scripts/train_vd11.sh --resume \
  --load_run '.*_vd11_motion_quality_long_20261113.*$' \
  --checkpoint '^model_[0-9]+\.pt$' \
  --num_envs 256 --max_iterations 3000 \
  --run_name vd11_motion_quality_long_20261113_resume
```

`3000` 是本次**追加**更新数，改成计划剩余次数即可。Ctrl+C 不保证额外保存，
会从最近一次完整保存恢复，至多损失距上次保存的进度。此正则排除 `.partial`
文件，不选择 smoke/probe 目录。恢复会创建新日志目录，不覆盖原日志；若存在
一次启动失败而没有检查点的新目录，应显式填入最近一个确有 checkpoint 的
完整目录名，不要盲选无模型目录。

完成充分训练后，再决定保留还是调整本候选；最终仍需新枪的 MuJoCo 同条件验证，
不能用 Isaac 回报、回合跑满或世界路径投影误差替代枪尖摆动和落脚冲击验收。
