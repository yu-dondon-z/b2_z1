```bash

bash scripts/train_vd13.sh \
  --resume \
  --load_run '2026-11-15_23-51-49_vd13_mount75_resume' \
  --checkpoint 'model_.*.pt' \
  --run_name vd13_mount75_resume \
  --max_iterations 3000
```

这里`--max_iterations 3000`表示从载入点再训练3000轮。自动选择该run编号最大的完整checkpoint；恢复策略、AMP、优化器、轮数与课程，写入新的run目录。不要再加`--vd13-from`，不要用旧`--vd5-warm-start`。修改安装／工作距离的检查点会被拒绝作为同版本恢复。

先以固定配置连续训练6000轮，再结合末段趋势、完整地面课程及运动回放判断是否继续；6000是训练预算，不是收敛保证。未收敛且没有明确失败证据时优先同配置续训，不凭几轮检查改奖励。
