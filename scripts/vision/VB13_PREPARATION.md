# VB13：先学会带载准备，再增加行走

VB12 训练中的前进指标较高，但 3kg 冷起步的准备能力没有过关。
本版保留 VB12 分支，另建 VB13，不修改实机及 rl_sar 部署程序。
仍由一个 70 维输入、18 维输出的 AMP 全身 actor 控制腿和机械臂；没有固定机械臂。

## 五级课程

| 级别 | TCP目标离地高度 | 等效悬挂软管 | 任务 |
|---|---:|---:|---|
| 0 | 7cm | 0kg | 带真实枪体，稳定准备/保持 |
| 1 | 5cm | 1kg | 加载后保持 |
| 2 | 3cm | 3kg | 标称加载后保持 |
| 3 | 1cm | 3kg | 最终工作高度保持 |
| 4 | 1cm | 3kg | 准备通过后沿曲线行走 |

枪体在所有级别保留真实质量、惯量和碰撞；0kg仅指暂不施加软管负载，
不是无枪/无重力。最终高度仍为1cm。尚不宣称覆盖1～10kg负载范围。
前四级不行走是有意安排，不是程序失效。

## 训练改动

- 训练和播放都使用实测准备门槛；第4级不能靠时间到达绕过准备检查。
- 准备阶段去掉零命令速度跟踪及沿路径速度奖励，避免“站着不动”被当成完成运动。
- 加强最终准备姿态误差、离地高度和接触惩罚，只在确实达到准备条件时奖励保持。
- 每回合准备成功/失败仍有一次性信号；身体/枪碰撞、低机身和倾倒终止保持。
- 增加训练专用 URDF 重力参考：先求目标实际关节姿态 `q*`，
  然后使用 `q_des=q*+tau_gravity/kp` 计算 PD 持载参考。
  力矩由各臂连杆/枪体 COM 和软管作用点计算，偏置有界并限制在原有安全参考范围。
  静态模型不能代替动态载荷验证；残余误差仍由 PPO 学习。
- 教师只作用于训练辅助损失，不改 rollout 的动作、不写电机、不进入播放/导出。
  相比 VB9 主要约束零空间，本版准备阶段使用完整姿态参考损失。
- 降低准备阶段探索：Z1 初始 std=0.025、范围0.005～0.04；
  腿初始0.06、上限0.08。第4级腿初始0.15、上限0.35。
  腿/臂都继续训练，仍保留 AMP、旧策略本体参考、动作EMA=.20、动作缩放=.25。
- 逐级固定已知负载，合格后才升级；暂不同时扩大量化不了的质量随机域。
  原有基座/增益等随机化仍保留，参考使用实际增益的环境均值。

## 增益与力矩：以生效配置为准

本次训练保存的 Z1 配置是名义刚度160、阻尼5、仿真力矩限值120Nm，
不是基础资产文件里的60刚度和30/60Nm限值。本版没有提高这些参数。
代表性1cm工作姿态，枪体+3kg软管的关节2重力补偿力矩约63Nm，
在120Nm仿真限值内，但不能据此认定实机能够承受。
启动时会打印实际增益、实际限值和代表姿态静态力矩比；
超过80%或运动学参考残差超过1.5cm则拒绝训练。
这只筛掉明显不合理设置，并不是全面动态/实机安全认证。

## 开始第0级

在开发电脑终端执行，不是在B2板载电脑：

```bash
cd /home/dong/b2_z1
bash scripts/rsl_rl/train_amp_vb13_prepare.sh
```

默认从 VB10 的 `model_12300.pt` 重新续训，新增500轮、256环境，
不是从退化的VB12最终权重开始。运行与调试选择：
`VB13：带载准备第0级（500轮＋自动验收）`。
长训没有自动启动。Ctrl+C 只停止该入口自己创建的任务。

完整训练日志在 `outputs/vb13_stage<级别>_<时间>_<PID>/training.log`。
训练结束后**自动进行确定性 actor 冷起步验收**，两个seed分别测试。
不通过会保存权重和失败原因，退出码1；这不等于训练进程崩溃。

## 升级条件

- 前四级：每个seed30秒无重置；5秒准备宽限之后至少90%采样满足：
  TCP 3D误差<8cm、Z误差<1cm、枪接触力<5N、几何离地间隙>5mm、
  机身高度>45cm、倾角<0.10rad、机械臂最大关节速度<0.8rad/s。
- 第4级每seed60秒，还要求有前进命令的比例≥70%、净世界X前进>3m，
  中心线误差P95<10cm、航向误差P95<0.12rad。
- 任何触地/身体碰撞/倾倒/超时重置、非有限数据都不能通过。
  准备阶段不因没有速度命令而被“运动退化”监控误停。
- 成功后保存 `acceptance.json`，绑定级别、checkpoint路径和SHA256，
  打印**下一阶段命令**，但不会自动开始下一阶段。
- 第1～4级要求上一阶段通过的证书，且与加载的权重一致；失败权重不能直接升级。
  相同级别的重新训练仍需重新验收。
- 第4级通过后，再使用完整视觉验收；合成曲线通过不等于视觉通过，更不等于允许上实机。

请使用程序打印的下一阶段命令，不需要猜路径。例如：

```bash
bash scripts/rsl_rl/train_amp_vb13_prepare.sh --stage 1 \
  --checkpoint /绝对路径/第0级训练目录/model_XXXXX.pt \
  --previous-acceptance /绝对路径/第0级输出目录/acceptance.json
```
