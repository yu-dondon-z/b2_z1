# VA14 从头训练

学生策略、价值网络、AMP 判别器及优化器重新初始化，从第 0 轮开始。
独立冻结的 VA7/7999 actor 只提供六个机械臂动作的训练参考，不将其权重
复制进学生，不约束腿部动作。部署仍为单个 70 维观测、18 维动作全身策略。
机械臂参考在随机学生访问的状态上也可能不准确，需要结合 TCP 与姿态指标评估。

## 配置

- PPO 固定学习率 2e-4，clip 0.2，5 epochs，4 minibatches，梯度裁剪 0.5。
- 腿部初始探索 std 0.50；按实际关节索引设置机械臂 std 0.15，允许学习。
- 机械臂参考损失权重 5.0，腿部参考为 0；保留 AMP 与 TCP 平滑奖励。
- 初始 80% 直线，其余左右圆弧，半径 24–36 m、速度 0.16–0.24 m/s。
- 通过门槛后逐步到 40% 直线、半径 6–12 m、速度 0.20–0.38 m/s。
- 升级检查跟踪、机身高度、对角接触及长时间接地指标，并要求失败率
  不超过 1%、平均回合长度不低于 95%，连续两批通过；不会按轮数强制升级。
- 机身低于 0.39 m、非法接触或姿态异常触发终止。

日志中的 `params/training_cli.yaml` 保存参考权重路径及损失参数，
`env.yaml` 和 `agent.yaml` 保存环境和算法配置。新配置的稳定性与收敛
尚需长训练验证，不能由短训练启动成功推断。

2026-09-28 已完成 128 环境、10 轮启动验证：检查点编号为 0 和 9，
resume=false，参考损失正常记录，标量日志无 NaN/Inf。六个机械臂动作
索引为 8、13、14、15、16、17，噪声初始化没有误改腿部动作。
随机策略初期频繁触发低高度终止，后续应检查回合长度能否持续增长。

中断续训时需要使用 `train_amp.py --resume`，指定 VA14 的运行目录及检查点，
继续传入相同的 `--teacher-checkpoint` 和 `--arm-teacher-weight 5.0`，
不传 `--initial-arm-policy-std`，也不重置优化器。`--max_iterations` 是新增轮数。
